# Инструкции Copilot

Это небольшое демонстрационное приложение на Node.js, Express и EJS для показа хайку.

- Сохраняй простую структуру Express + EJS.
- Серверный код находится в `index.js`, шаблоны — в `views/`, статические файлы — в `public/`.
- Данные хайку хранятся в `haikus.json`. Сохраняй существующую структуру объектов с полями `text` и `image`.
- Не добавляй зависимости и сложные инструменты без необходимости.
- Делай небольшие изменения и сохраняй код понятным для начинающих.
- При изменении JSON проверяй его корректность.
- При изменении шаблонов или стилей проверяй ссылки на статические файлы.
- Для проверки приложения используй `npm start`.
